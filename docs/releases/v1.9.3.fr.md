## Plus d'identification sur le tableau de bord local

Les réglages, le journal, les sauvegardes et les mises à jour du tableau de bord local
s'ouvrent maintenant directement, sans demander de nom d'utilisateur ni de mot de passe.

- Le **mot de passe web est facultatif** et vide par défaut. Sans lui, rien n'est jamais
  demandé. La mise à jour vers la 1.9.3 **efface, une seule fois, un mot de passe défini
  avec une version précédente**, pour qu'aucune fenêtre d'identification n'apparaisse non
  plus après la mise à jour.
- Pour protéger un miner sur un réseau partagé, redéfinis un mot de passe dans
  *Réglages* → *Réseau* → **Mot de passe web** (ou dans le portail de configuration) : il
  est alors demandé avant toute modification, comme avant, et conservé lors des mises à
  jour. Vider le champ le supprime.
- Sans mot de passe, **n'importe qui sur ton réseau local peut changer les réglages**,
  y compris l'adresse de paiement, télécharger les sauvegardes (elles contiennent le mot
  de passe Wi-Fi) et envoyer un firmware. Garde le miner sur ton réseau domestique et
  n'ouvre jamais son port 80 sur Internet ; voir la
  [politique de sécurité](../../SECURITY.md).

Rien d'autre ne change depuis la [1.9.2](v1.9.2.md).

## Installation et compatibilité

Les appareils BDLMiner déjà installés reçoivent leur **`*-firmware.bin`** signé
correspondant par la recherche de mises à jour GitHub (en période d'essai) ou par la page
locale de mise à jour ; les réglages, les statistiques et l'historique du hashrate sont
conservés (sauf le mot de passe web, comme expliqué ci-dessus). Pour une première
installation, choisis la carte dans l'[installateur web](https://bdlglua.github.io/BDLMinerV1/)
ou flashe son **`*-factory.bin`** à l'adresse 0x0. Firmwares signés, signatures, images
complètes, sommes SHA-256 et installateur web sont fournis pour les **douze variantes**.
L'agent utilisateur natif par défaut est **BDLMinerV1/1.9.3**.

## Validation

- Tests natifs sur PC (nouveaux : l'ancien mot de passe effacé une seule fois et un
  nouveau conservé, l'envoi d'un firmware sans mot de passe, un mot de passe vidé), 75
  tests de non-régression dans le navigateur.
