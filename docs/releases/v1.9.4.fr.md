## Le modèle exact des cartes M5Stack

Les [statistiques BDLMiner](https://bdlminer-stats.bdlminer-bot.workers.dev/) et le
[site](https://bdlglua.github.io/BDLMinerV1/#stats) distinguent maintenant les cartes
M5Stack. Le firmware M5Stack sert plusieurs modèles (Core, Core2, Tough, StickC Plus,
Atom…, et en ESP32-S3 l'AtomS3, le CoreS3, le Cardputer…), qu'il détecte déjà au
démarrage pour son écran : le rapport anonyme du hashrate indique maintenant ce modèle,
par exemple
`{"v":"1.9.4","board":"m5stack-esp32","hashrate":1.02e6,"every":300,"model":"M5Stack Core2"}`.
Sur le site, *Appareils* liste les modèles en ligne sous leur firmware et *Par carte*
affiche une ligne par modèle.

Le modèle n'est envoyé que s'il apporte plus que le nom du firmware ; les autres cartes
envoient exactement la même chose qu'avant. Rien d'autre ne change dans le rapport : ni
adresse, ni worker, ni pool, ni nom, ni identifiant. *Réglages* → *Statistiques
anonymes* → **Partager mon hashrate anonymement** permet toujours de le désactiver.

Le service de statistiques compte aussi tout de suite plusieurs miners d'une même carte
qui démarrent ensemble ; ils n'étaient comptés qu'une fois tant que leurs rapports ne
couvraient pas cinq minutes.

Rien d'autre ne change depuis la [1.9.3](v1.9.3.md).

## Installation et compatibilité

Les appareils BDLMiner déjà installés reçoivent leur **`*-firmware.bin`** signé
correspondant par la recherche de mises à jour GitHub (en période d'essai) ou par la page
locale de mise à jour ; les réglages, les statistiques et l'historique du hashrate sont
conservés. Pour une première installation, choisis la carte dans
l'[installateur web](https://bdlglua.github.io/BDLMinerV1/) ou flashe son
**`*-factory.bin`** à l'adresse 0x0. Firmwares signés, signatures, images complètes,
sommes SHA-256 et installateur web sont fournis pour les **douze variantes**. L'agent
utilisateur natif par défaut est **BDLMinerV1/1.9.4**.

## Validation

- Tests natifs sur PC (nouveaux : le modèle dans le rapport, seulement quand il apporte
  plus que le nom du firmware, caractères inattendus écartés) et 75 tests de
  non-régression dans le navigateur ; les tests du service de statistiques couvrent les
  modèles et les miners qui démarrent ensemble.
