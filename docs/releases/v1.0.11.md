## Local website fixes

- Fixed settings being submitted before loading, invalid values being saved, and duplicate saves while restarting.
- Added retry controls and visible errors for settings, backup restoration, firmware uploads and log refreshes.
- Prevented overlapping dashboard requests and corrected zero-hashrate and linked-miner displays.
- Preserved exact lifetime counters when restoring backups and improved mobile form layout.
- Hardened web firmware updates: authenticate every request, reject factory images and multiple files, and activate firmware only after the complete request is accepted.

## GitHub updates

- Added an always-visible update status tile and a **Check now** button, including errors when no update is available.
- Added a small `update.json` release asset for discovery without the shared GitHub API rate limit. Older releases remain discoverable through the API fallback.
- Check 30 seconds after boot, then hourly, retrying failed checks after five minutes.
- Prioritize firmware checks over optional network requests and report checks waiting for WiFi or free memory.
- Prevent duplicate installation requests while preserving firmware signature verification and exclusive OTA ownership.

## Upgrade notes

Settings and statistics are preserved. If the installed firmware cannot retrieve GitHub updates, install the matching `<board>-firmware.bin` once through **Settings → Firmware update**. Boards without two application slots require USB. Use `<board>-factory.bin` only for a factory installation by USB.

No physical device was connected during validation. Browser regressions, production upload and updater simulations, host tests, release packaging tests and builds for all 10 boards were checked.
