# BDLMiner V2 2.4.2

Pool statistics and Bitaxe Gamma 601 fixes; settings, pool profiles and mining kernels
are otherwise unchanged from [2.4.1](v2.4.1.md).

- **public-pool statistics are back on the dashboard.** public-pool.io now serves its
  statistics API (port 40557) over **TLS 1.3 only**, which the firmware's TLS (1.2)
  cannot use, so *Seen by the pool* fell back to an estimate. When the miner finds no
  statistics API, the dashboard now asks `https://<pool host>:40557/api/client/<address>`
  itself, from your browser, at most every 10 minutes, and shows the pool's figures
  marked *read by this browser*. Only the address is sent, not the worker name. The
  figures appear while the dashboard is open; the miner's screen keeps the estimate.
- **No more statistics searches at every share.** A fruitless search for the pool's
  API ran again after each accepted share. That rule is meant for a pool that only
  publishes an address after its first share; a Gamma finds shares every minute, so
  all ten probes ran again every 30 minutes. It now follows only a search that found
  an API not knowing the address yet (HTTP 404); other failures wait 6 hours.
- **The log says why.** Each failed statistics probe is logged with its cause (TLS
  error, HTTP status, timeout), and a pool refusing TLS 1.2 is named as such.
- **Bitaxe Gamma 601: the 525 MHz fallback survives restarts.** A higher profile that
  failed fell back to 525 MHz until the next reboot only, so every restart, update or
  power cut went back to the failing profile. The fallback is now kept, with its
  reason, while that profile stays selected; choosing another frequency clears it.

## Validation

Browser regressions cover the dashboard's own request to public-pool, its tile, and
its absence when the miner reads the API; host regressions cover the fallback kept
across a restart and cleared by another profile, with all host, browser and board
builds. The public-pool request was checked against a simulated answer, not the live
API. No physical board was used for this validation.
