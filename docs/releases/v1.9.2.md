## Live statistics

The [BDLMiner statistics](https://bdlminer-stats.bdlminer-bot.workers.dev/) and the
[site](https://bdlglua.github.io/BDLMinerV1/#stats) now follow the miners live: the
total hashrate, the devices online (green) and offline (red) for each board, and a
24-hour chart with a point every 5 minutes, ending with the total right now. The
pages refresh every 20 seconds.

For that, the anonymous hashrate report goes **every 5 minutes** instead of once an
hour, the first one 3 minutes after boot. It also says how long it stands for
(`"every": 300`), which lets the service add the reports up without identifying the
miners: it is still only the **firmware version, the board and the hashrate**, for
instance `{"v":"1.9.2","board":"m5stickc-plus2","hashrate":1.02e6,"every":300}`. No
address, worker, pool, name or identifier. Turn it off at any time: *Settings* →
*Anonymous statistics* → **Share my hashrate anonymously**.

Miners on 1.9.0 and 1.9.1 keep reporting hourly and are counted as well, with up to
an hour of delay, until they update.

## Installation and compatibility

Existing BDLMiner devices install their matching signed **`*-firmware.bin`** through
GitHub update discovery (as a firmware trial) or the local firmware-update page;
settings, statistics and the hashrate history are kept. For a first install, pick the
board in the [web flasher](https://bdlglua.github.io/BDLMinerV1/) or flash its
**`*-factory.bin`** at 0x0. Signed firmware, signatures, factory images, SHA-256
checksums and the web flasher are provided for all **twelve variants**. The default
native user agent is **BDLMinerV1/1.9.2**.

## Validation

- Native host tests (the report's content and its 5-minute schedule) and 75 browser
  regressions; the statistics service's tests cover miners reporting every 5 minutes
  and hourly together, without counting one twice, and it ran in Cloudflare's runtime
  before going live.
- Hashrate sharing itself is confirmed on boards since 1.9.0: an ESP32 and an
  M5StickC Plus2 reported within the hour after that release.
