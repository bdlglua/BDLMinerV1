## 64-bit share statistics

- Add a 64-bit share counter to the local dashboard, with English/French labels and an estimated average interval based on the current hashrate.
- Count fully verified hashes with at least 64 leading zero bits using their exact digest bytes. The counter starts at zero after each restart, like the existing session share statistics.
- Expose the counter as `over64bits` in `/api/stats`, `bdlminer_shares_64bit_total` in Prometheus and `shares64` in MQTT/Home Assistant.

This is a statistics addition. Accelerated SHA loops, processor architecture, mining power and thermal protection are unchanged. At 1 MH/s the expected interval is about 585,000 years; this is a statistical average, not a prediction.
