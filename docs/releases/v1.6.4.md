## Reliability fixes from a full code review

A review of the whole firmware found no fault in mining, share submission,
Stratum V1/V2, signatures or persistence. It found five smaller defects, fixed here:

- **Refused GitHub updates are no longer retried every hour.** With automatic
  installation, a release whose signature was rejected was downloaded again
  (about 2 MB, with mining paused) every hour; boards without room for a second
  firmware (M5Stack Core, CYD) repeated the same refusal. A refused version is now
  only installed when asked for from the dashboard.
- **Paused mining no longer counts as "no accepted share".** With *Restart after
  N hours without an accepted share* enabled (off by default), a miner paused by
  its power setting, the temperature limit or a firmware update restarted every
  N hours. Paused time no longer counts.
- **Pools without an HTTPS statistics API no longer stall the market task.**
  Pools other than public-pool.io and ckpool are tried as ckpool; one without
  HTTPS on port 443 made each attempt wait about 18 s for the TLS timeout, every
  hour, delaying price refreshes and update checks. After such a failure the pool
  is not asked again until the next restart. Known pools are still retried.
- **Restored backups keep the best shares in order.** JSON rounding can slightly
  reorder the ten best shares of a backup; they are now sorted before being saved,
  so new records are ranked correctly.
- **Classic ESP32: SHA engines are released when the hardware loops give up.**
  If every hardware loop had been disabled after wrong hashes, the miner kept the
  SHA engines locked instead of returning them to TLS.

Hashing code, assembly timing, thermal limits and the 10-second dashboard refresh
of 1.6.3 are unchanged.

## Installation and compatibility

Existing BDLMiner devices install the matching signed **`*-firmware.bin`** through
GitHub update discovery or the local firmware-update page. For M5StickC Plus2, use
**`m5stickc-plus2-firmware.bin`**. Settings and saved statistics are kept by an
application update. Factory images are for USB installation and erase settings.

Signed firmware, signatures, factory images, SHA-256 checksums and the
[web flasher](https://bdlglua.github.io/BDLMinerV1/) are provided for all **eleven
variants**. The default native user agent is **BDLMinerV1/1.6.4**.

Gamma 601 support and profiles above 525 MHz remain experimental and unvalidated
on a physical board.

## Validation

- Native host tests, including a new case: a refused release is not reinstalled
  automatically but can still be installed on request. The host tests also passed
  under AddressSanitizer and UndefinedBehaviorSanitizer.
- Eleven board builds; no new compiler warning in the firmware sources.
- On an M5StickC Plus2 mining on eu.findmyblock.xyz: self-tests passed, about
  1004 kH/s, no rejected share, and the pool statistics lookup stopped after its
  first TLS failure instead of retrying every hour.
