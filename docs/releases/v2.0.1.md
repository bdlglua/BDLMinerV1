# BDLMiner 2.0.1

Complete the V2 naming change on the firmware, website and project links.

- Use **BDLMiner V2** in the setup portal, boot log, splash renderer and current
  guides. The setup Wi-Fi network is now `BDLMinerV2-XXXX`.
- Use `BDLMinerV2/<version>` as the native Stratum identity. Saved V1/V2 native
  identities migrate to the current version; explicit custom identities and the
  existing one-time NerdMiner compatibility fallback are preserved.
- Point updates, usage reports, tools and documentation at
  `bdlglua/BDLMinerV2` and the installer at
  <https://bdlglua.github.io/BDLMinerV2/>.
- Preserve firmware signatures, saved Wi-Fi/pool settings, lifetime statistics,
  mining kernels, clocks and thermal/electrical safeguards. Internal legacy
  transport/version markers remain so older offline OTA tools can verify images.

The previous 2.0.0 release is retained. This patch does not claim new physical
hashrate or thermal measurements.

## Updating existing installations

Normal signed updates on the stable channel follow GitHub's repository redirects
when the old name is left unused. The repository owner must not create another
repository named `BDLMinerV1`, which would remove that redirect.

**GitHub Pages project addresses do not redirect automatically.** Use the new
installer address above. Devices on a beta channel in 2.0.0 or older may still
request the old Pages address: select **stable** in the miner's update settings
and check for updates, or upload the matching signed release's
`<board>-firmware.bin` through its existing local dashboard. Do not upload a
factory image as OTA. After installing 2.0.1, beta selection uses the new address.

See the [migration record](../v2/repository-migration.md) for operator steps and
the distinction between automated tests and the post-rename live checks.
