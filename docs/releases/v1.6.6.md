## New screen, new dashboard, smaller firmware

### One big number per page on the miner's screen

Each of the eight pages now shows one value as large as the panel allows (up to
80 pixels high on 320x240 screens): live hashrate, local time, Bitcoin price, block
height, the miner's IP address, average hashrate with its graph, best difficulty
ever, and the block being mined. Three secondary readings sit under it, side by
side on landscape panels and stacked on portrait ones, where the unit moves under
the value. A thin header shows a Bitcoin coin, the page name and the miner state
(`LIVE`, `OFFLINE`, `+1 SHARE`, `COOLING`, `PAUSED`, `LIMITED`, `BATTERY`). The
setup, startup and update screens use the same style. The illustrations of earlier
versions are gone (128 KB of flash).

### A compact console for the web dashboard

Key figures come first: hashrate, shares, best difficulty, temperature, power and
uptime. On large screens the hashrate history and records sit in the main column,
with pool, Bitcoin network, device and update panels beside them; on phones
everything stacks. Tiles are denser, the chart is taller and there is less text. The
settings and log pages share the new style.

When a pool has no readable statistics API, the *Seen by the pool* card now
estimates what the pool credits from the accepted shares (their difficulty x 2^32
over the session) instead of showing a dash. The empty temperature chart no
longer claims that a sensor is missing during the first five minutes.

### Smaller firmware, updates for every board

The firmware, the Arduino core and the libraries are built for size (`-Os`), while
the mining code keeps `-O2`; hashrate is unchanged on an M5StickC Plus2. With the
illustrations removed, every board is 140-340 KB smaller:

| Board | 1.6.5 | 1.6.6 | Slot |
|---|---|---|---|
| LilyGO T-Display | 1.95 MB | 1.65 MB | 98.9% -> 83.8% |
| M5StickC Plus2 | 2.13 MB | 1.79 MB | |
| M5Stack Core | 2.09 MB | 1.76 MB | now OTA |
| ESP32-2432S028R (CYD) | 1.95 MB | 1.65 MB | now OTA |

**M5Stack Core and CYD now get two firmware slots**, so they can update from GitHub
and from the dashboard. Boards of these two models installed before 1.6.6 have a
single slot: reinstall them once by USB or with the
[web flasher](https://bdlglua.github.io/BDLMinerV1/) using the 1.6.6 factory image.

## Installation and compatibility

Existing BDLMiner devices install the matching signed **`*-firmware.bin`** through
GitHub update discovery or the local firmware-update page. For M5StickC Plus2, use
**`m5stickc-plus2-firmware.bin`**. Settings and saved statistics are kept by an
application update. Factory images are for USB installation and erase settings.
Reload the dashboard after updating so the browser loads the new pages.

Signed firmware, signatures, factory images, SHA-256 checksums and the web flasher
are provided for all **eleven variants**. The default native user agent is
**BDLMinerV1/1.6.6**. Gamma 601 support and profiles above 525 MHz remain
experimental and unvalidated on a physical board.

## Validation

- Display renderer: eight pages, English and French, seven panel sizes, identical
  strip and direct rendering, no redraw of unchanged fields, bounded extreme values.
- 66 browser regressions, native host tests and release-tool tests; eleven board builds.
- On an M5StickC Plus2: about 1005 kH/s (hardware 949 + software 41 + idle-cycle
  15 kH/s) as before, no rejected share, and the pool-side estimate at 960 kH/s after
  93 shares (it converges as shares accumulate).
