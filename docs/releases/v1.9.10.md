## Overclocking the Gamma, and three boards better supported

### Bitaxe Gamma 601 and NerdNOS

- **No more restarts from the thermal rule.** On a Gamma at 600 MHz the ASIC restarted
  every 40 seconds: at 55 °C (the 65 °C limit minus 10), the thermal rule halved the
  power, which restarts an ASIC; once off it cooled at once (its own sensor is silent
  then), so the power came back and the ASIC restarted again. About a quarter of the
  hashing time was lost, and at the stock 525 MHz the ASIC sat just below that
  threshold. ASIC boards now have no 50 % and 25 % steps below the limit, and once hot
  they stay paused at least two minutes. ESP32 boards keep their steps.
- **550, 600 and 625 MHz verified** on a real Gamma at 1150 mV: 1.126, 1.225 and
  1.267 TH/s, ASIC up to 58 °C, regulator up to 71.5 °C, 16.9 A, hardware errors 0.2 %,
  no restart. Higher profiles stay untested.

### ESP32-S3 and ESP32-C3 without a screen

- **The log over native USB.** Boards with only their native USB port, such as the
  Super Mini, never showed the log. It now goes to the native USB port and to UART0 as
  well, so DevKits still show it through their USB-serial chip. Nothing waits when no
  USB host listens.

### CYD (ESP32-2432S028R)

- **The version with two USB ports.** It carries an ST7789 display instead of the
  ILI9341: same commands, inverted colours. The firmware reads the display's ID at boot
  and inverts the colours when it is an ST7789.

### Releases

- Each release now reports how full every board's update slot is, and warns from 95 %,
  before an image no longer installs over WiFi (the M5Stack ESP32 build fills 93 %).

Nothing else changes since [1.9.9](v1.9.9.md).

## Installation and compatibility

Existing BDLMiner devices install their matching signed **`*-firmware.bin`** through
GitHub update discovery (as a firmware trial) or the local firmware-update page;
settings, statistics and the hashrate history are kept. For a first install, pick the
board in the [web flasher](https://bdlglua.github.io/BDLMinerV1/) or flash its
**`*-factory.bin`** at 0x0. Signed firmware, signatures, factory images, SHA-256
checksums and the web flasher are provided for all **twelve variants**. The default
native user agent is **BDLMinerV1/1.9.10**.

## Validation

- On a real Bitaxe Gamma 601: the restart loop at 600 MHz recorded second by second,
  then no restart at 600 and 625 MHz with this version.
- The native USB log and the CYD's ST7789 are built and reviewed but not yet tried on
  those boards: feedback is welcome.
- All native host tests (new: the ASIC thermal rule, the update slot report), 75 browser
  regressions, the release tool tests and the twelve builds pass.
