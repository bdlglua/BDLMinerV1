## NerdNOS support (experimental)

BDLMiner now runs on the [NerdNOS](https://github.com/benjamin-wilson/NerdNOS): one
**BM1397** ASIC (the Antminer S17 chip) on a board that carries a LilyGO T-Display-S3.
The T-Display-S3 shows the usual screens and web dashboard and drives the ASIC. The
stock firmware announces 150–200 GH/s for about 8 W.

- Pins and start-up follow the NerdNOS firmware that ships on the boards: UART on
  GPIO17/18, reset on GPIO12, the core supply on GPIO13, an NTC on GPIO2.
- 300 MHz at 100 % mining power, scaled by the *Mining power* setting; a job every
  30 ms with four rolled versions (the pool must support version rolling and a
  difficulty of 16 or more).
- Every result from the chip is verified by hashing it before it counts or is
  submitted; the hashrate comes from these verified results, and corrupted frames
  are reported as hardware errors on the dashboard's *ASIC · BM1397* tile.
- Mining pauses at 75 °C by default; a silent chip is started again after a minute.
- GitHub updates are offered rather than installed automatically, as for the Gamma.

**No physical NerdNOS was available.** The chip protocol and the board code are tested
on a PC (command vectors, a chip-side replay of every midstate, a real proof of work
from the genesis block), but the start-up on a real board, the actual hashrate and
accepted shares still need confirmation. See [the hardware notes](../hardware/nerdnos.md).

The screen also shows GH/s and TH/s for ASIC boards. Nothing changes for the other
boards since [1.7.2](v1.7.2.md).

## Installation and compatibility

Flash **`nerdnos-factory.bin`** at 0x0, or pick **NerdNOS** in the
[web flasher](https://bdlglua.github.io/BDLMinerV1/). Existing BDLMiner devices install
their matching signed **`*-firmware.bin`** through GitHub update discovery (as a
firmware trial) or the local firmware-update page; settings, statistics and the
hashrate history are kept. Signed firmware, signatures, factory images, SHA-256
checksums and the web flasher are provided for all **twelve variants**. The default
native user agent is **BDLMinerV1/1.8.0**.

## Validation

- Native host tests (new: BM1397 protocol and NerdNOS backend), 75 browser
  regressions and twelve board builds.
