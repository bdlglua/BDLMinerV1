# BDLMiner V2 2.3.3

Corrections ; réglages, statistiques et noyaux de minage inchangés.

- **Fonctionne sur les réseaux qui bloquent NTP.** Depuis la 2.3.1, les certificats
  HTTPS sont vérifiés avec l'horloge : sans NTP, aucune notification, donnée de
  marché ni statistique de pool ne pouvait être obtenue. Après une minute sans NTP,
  l'horloge est réglée sur l'heure des jobs de la pool (à quelques minutes près) ;
  NTP la corrige dès qu'il répond.
- **Nom sur le routeur.** Le mineur s'annonce désormais `bdlminer-xxxx` (son nom
  mDNS) au lieu de `esp32-xxxxxx`. Ouvrir le tableau de bord par le nom que lui donne
  le routeur (par exemple `bdlminer-xxxx.fritz.box`) est accepté pour les réglages.
- **MQTT** n'indique plus *connecté* quand le WiFi est coupé.
- **Les refus de la pool indiquent la valeur refusée.** L'*Authorization validation
  error* de public-pool apparaît dans le journal avec la valeur rejetée, par exemple
  l'adresse de paiement : une faute de frappe se repère tout de suite.
- **Durées à l'écran :** plus de « 60min » ni de « 1d 24h », chaque unité est tronquée.
- **Bitaxe Gamma 601 :** l'OLED n'est écrit que lorsque sa luminosité change, au lieu
  de chaque seconde sur le bus I2C partagé avec l'ASIC.

## Validation

Des tests sur PC exécutent le code réel du repli d'horloge, du détail des refus de
pool et des durées à l'écran, avec tous les tests et la compilation de chaque
carte. Aucune carte physique n'a servi à cette validation.
