# BDLMiner 2.0.0-beta.3 — development preview

The owner confirmed the M5 beta.2 OTA, then reported a remaining empty area
under pool diagnostics and unclear settings-menu symbols.

- The chart, pool and Bitcoin panels now use one full-width flow. A taller
  Bitcoin panel can no longer leave an empty column beneath pool diagnostics.
  Pool/network cards adapt within their sections; mobile views keep their bounds.
- Settings groups, maintenance, backup, firmware upload and restart use inline
  SVG icons with text labels. They no longer depend on font glyphs. Icons remain
  hidden from screen readers and require no external assets or network requests.
- Earlier beta.2 logo, browser titles, detail-panel and host-collector fixes remain.

Mining kernels, clock, voltage, cooling controls and device polling are unchanged.
Software checks are not beta.3 hardware acceptance. The owner M5 runs beta.2 and
Gamma beta.1; use the matching previous version in each manual OTA observer.
The longer Gamma check remains incomplete after its HTTP-read interruption;
that read's underlying cause has not been established.

This CI kit contains unsigned development images, with no automatic installation.
Stable firmware remains 1.9.15. See the
[manual OTA instructions](../v2/README.md#manual-ota-on-the-owners-cards).
