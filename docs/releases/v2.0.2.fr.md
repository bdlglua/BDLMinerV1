# BDLMiner 2.0.2

Les statistiques publiques affichent maintenant une répartition **par pool**, avec
le nombre de mineurs et leur hashrate total. Ce tableau est disponible sur le site
BDLMiner et sur la page du service de statistiques.

Pour participer, active **Réglages → Réseau → Statistiques anonymes → Partager ma
pool anonymement**. L’option est désactivée par défaut, y compris après une mise à
jour, et nécessite aussi **Partager mon hashrate anonymement**. Les deux réglages
s’appliquent sans redémarrage.

Seul un groupe de pool publique prédéfini est envoyé. Les autres hôtes deviennent
**Autre / pool privée** directement sur la carte : aucun nom d’hôte configuré, port,
adresse Bitcoin ni worker n’est envoyé. La pool de secours est utilisée lorsqu’elle
est connectée. Les anciennes versions, le partage de pool désactivé et les pools
déconnectées restent comptés dans **Pool non renseignée**.

Les douze profils conservent les mises à jour signées et le retour arrière
automatique. Les mesures physiques restent celles du M5StickC Plus2 et du Gamma
601 déjà enregistrées ; cette version n’annonce aucun nouveau gain de hashrate.
