# BDLMiner V2 2.3.3

Fixes; settings, statistics and mining kernels are unchanged.

- **Works on networks that block NTP.** Since 2.3.1 HTTPS certificates are checked
  against the clock, so without NTP no notification, market data or pool statistics
  could be fetched. After a minute without NTP, the clock is set from the pool's job
  time (within minutes); NTP still corrects it whenever it answers.
- **Router name.** The miner now registers as `bdlminer-xxxx` (its mDNS name) with
  the router instead of `esp32-xxxxxx`. Opening the dashboard through the router's
  own name for it (for example `bdlminer-xxxx.fritz.box`) is accepted for settings.
- **MQTT** no longer reports *connected* while WiFi is down.
- **Pool refusals name the refused value.** public-pool's *Authorization validation
  error* now shows in the log with the value it rejected, for example the payout
  address, so a mistyped address is found at once.
- **Screen durations** no longer read "60min" or "1d 24h": each unit is truncated.
- **Bitaxe Gamma 601:** the OLED is only written when its brightness changes, instead
  of every second on the I2C bus shared with the ASIC.

## Validation

Host regressions run the production clock fallback, the pool refusal detail and
the screen durations, with all host, browser and board builds. No physical board
was used for this validation.
