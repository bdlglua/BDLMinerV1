## Fixes from a full audit

An audit of the miner, its local pages, MQTT, the site and the services behind it found
these bugs; all are fixed.

### Security

- **Other sites can no longer change the miner.** Without a web password, a page on any
  website, opened on the same network, could send the miner new settings (the payout
  address included), a firmware or a restart. Settings, backups, firmware uploads,
  restarts, crash reports and update checks now refuse a request from another site's
  page, or reaching the miner under another site's name (DNS rebinding). The miner's own
  pages work as before, by address or by `bdlminer-xxxx.local`.
- **Passwords and the webhook stay on the miner.** The settings page received the WiFi,
  MQTT and web passwords and the full webhook URL, with its token. A set secret now reads
  as `••••••••`; saving keeps it as it is, and emptying the field still clears it.
  Backups hold the secrets only when a web password protects them.

### Local dashboard

- **Pages load without stalls.** The miner served one connection at a time and waited
  up to 5 seconds on each spare connection a browser opens in advance: a page could hang
  for 10 seconds, and some of its files failed, which broke the page. New connections now
  wait their turn and the first one to ask is served: about 1 second, with no failures.
- **French numbers**: decimals with a comma (« 1,00 MH/s », « 52,8 °C ») and a space
  before the colon, as on the site.
- **Bigger switches on phones**, easier to tap.

### MQTT

- The first connection to the broker no longer waits 30 seconds after start-up.

Nothing else changes since [1.9.5](v1.9.5.md). The statistics service now refuses a
hashrate the board cannot reach, and the site's chat limits wrong admin keys (these run
online and need no update).

## Installation and compatibility

Existing BDLMiner devices install their matching signed **`*-firmware.bin`** through
GitHub update discovery (as a firmware trial) or the local firmware-update page;
settings, statistics and the hashrate history are kept. For a first install, pick the
board in the [web flasher](https://bdlglua.github.io/BDLMinerV1/) or flash its
**`*-factory.bin`** at 0x0. Signed firmware, signatures, factory images, SHA-256
checksums and the web flasher are provided for all **twelve variants**. The default
native user agent is **BDLMinerV1/1.9.6**.

## Validation

- On an M5StickC Plus2: a request from another site is refused (403) and the miner's
  own page still saves; the webhook reads `••••••••` and survives a save; the pages
  load in about 1 second with 4 idle connections open (10 seconds before), 18 page loads
  without an error on a computer, a phone and a 320 px screen; hashrate unchanged.
- 75 browser regressions, the native host tests (new: Host and Origin checks, an upload
  from another site refused before anything is written), the statistics and chat tests.
