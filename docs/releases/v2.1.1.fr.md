# BDLMiner 2.1.1

**Réglages → Pool → User agent** propose désormais un seul menu avec exactement
deux choix : **NerdMinerV2** et **BDLMinerV2/2.1.1**. Le portail de configuration et
la démo interactive proposent les mêmes choix. Le sélecteur Automatique/Manuel
et le champ de saisie libre sont supprimés. Le dashboard affiche l’identité
envoyée sans indication de mode.

Stratum V1/V2 et les pools principale/de secours utilisent l’identité choisie.
Un refus ne la remplace pas silencieusement. L’identité BDLMiner suit la version
du firmware ; un choix NerdMinerV2 est conservé après redémarrage, mise à jour et
restauration de sauvegarde. Les anciennes identités personnalisées deviennent
l’identité native actuelle. L’ancien indicateur de mode reste désactivé dans
les sauvegardes pour la compatibilité avec le retour arrière OTA.

Le choix BTC/BCH, les moteurs de minage, les protections ASIC, les mises à jour
signées et le retour arrière sont conservés.
