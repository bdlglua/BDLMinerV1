## A clearer local dashboard

- Put live hashrate, accepted shares, best difficulty and a compact device overview first. Move records below the charts and group advanced diagnostics in an expandable section.
- Rebuild the performance charts with readable axes, a zero baseline for hashrate, gradient area fill, min/max/average summaries and a configured-temperature-limit line.
- Link inspection across hashrate, temperature and effective power. Use a pointer, touch, arrow keys or Home/End to inspect actual samples, including missing observations and coverage.
- Add local 1 h, 6 h and 24 h windows, remember the selected window in the browser and export the displayed window as CSV. Window changes make no additional miner requests.
- Preserve the positions of missing samples and break lines across gaps. Handle zero-valued, empty and single-point histories without fabricated data. Chart times are relative to the latest recorded point and summaries use valid displayed samples.

## Less work during refresh

- Keep live metric nodes and chart elements between polls. Redraw charts only when history, the selected window, the temperature limit or the available width changes.
- Load diagnostics on demand and refresh other miners every 15 seconds. Local live stats retain the lightweight three-second polling request and history remains revision-based.
- Preserve keyboard focus during refreshes, improve small-screen layouts and translate the new controls into French and English. Everything remains served locally without external fonts, chart libraries or CDNs.

Mining kernels, requested power, thermal protection, settings and firmware update behavior are unchanged.
