## Prise en charge du NerdNOS (expérimentale)

BDLMiner fonctionne maintenant sur le [NerdNOS](https://github.com/benjamin-wilson/NerdNOS) :
un ASIC **BM1397** (la puce de l'Antminer S17) sur une carte qui porte une LilyGO
T-Display-S3. La T-Display-S3 affiche les écrans et le tableau de bord habituels et
pilote l'ASIC. Le firmware d'origine annonce 150 à 200 GH/s pour environ 8 W.

- Les broches et le démarrage suivent le firmware NerdNOS livré avec les cartes :
  UART sur GPIO17/18, reset sur GPIO12, alimentation de la puce sur GPIO13, sonde
  NTC sur GPIO2.
- 300 MHz à 100 % de puissance, ajustés par le réglage *Puissance de minage* ; un
  travail toutes les 30 ms avec quatre versions déroulées (la pool doit accepter le
  version rolling et une difficulté d'au moins 16).
- Chaque résultat de la puce est vérifié en le hachant avant d'être compté ou envoyé ;
  le hashrate vient de ces résultats vérifiés, et les trames corrompues apparaissent
  comme erreurs matérielles sur la tuile *ASIC · BM1397* du tableau de bord.
- Le minage se met en pause à 75 °C par défaut ; une puce muette est relancée au bout
  d'une minute.
- Les mises à jour GitHub sont proposées au lieu d'être installées automatiquement,
  comme pour le Gamma.

**Aucun NerdNOS physique n'était disponible.** Le protocole de la puce et le code de la
carte sont testés sur PC (vecteurs de commandes, rejeu côté puce de chaque midstate,
une vraie preuve de travail à partir du bloc genesis), mais le démarrage sur une vraie
carte, le hashrate réel et les shares acceptées restent à confirmer. Voir
[les notes matérielles](../hardware/nerdnos.md).

L'écran affiche aussi les GH/s et TH/s pour les cartes ASIC. Rien ne change pour les
autres cartes depuis la [1.7.2](v1.7.2.md).

## Installation et compatibilité

Flashe **`nerdnos-factory.bin`** à l'adresse 0x0, ou choisis **NerdNOS** dans
l'[installateur web](https://bdlglua.github.io/BDLMinerV1/). Les appareils BDLMiner
déjà installés reçoivent leur **`*-firmware.bin`** signé correspondant par la recherche
de mises à jour GitHub (en période d'essai) ou par la page locale de mise à jour ; les
réglages, les statistiques et l'historique du hashrate sont conservés. Firmwares
signés, signatures, images complètes, sommes SHA-256 et installateur web sont fournis
pour les **douze variantes**. L'agent utilisateur natif par défaut est
**BDLMinerV1/1.8.0**.

## Validation

- Tests natifs sur PC (nouveaux : protocole BM1397 et pilote NerdNOS), 75 tests de
  non-régression dans le navigateur et compilation des douze cartes.
