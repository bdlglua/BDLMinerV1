# BDLMiner V2 2.4.0

**Peercoin (PPC), proof of work** joins BTC, BCH, BSV, eCash and DigiByte SHA-256d
in **Settings → Pool → Cryptocurrency**. Choose a Peercoin **Stratum V1** pool,
its payout address or pool account, and a matching backup. The pool determines
the chain served; selecting PPC cannot change a shared pool account's coin.

Peercoin Base58Check and Bech32/Bech32m address checks use its own prefixes.
The height reader supports its timestamped transaction versions 1/2 and the
timestamp-free version 3. Coinbase hashing preserves the pool's bytes, and
the proof-of-work header is the standard 80-byte SHA-256d header. Public and
private statistics retain PPC separately. Bitcoin market, halving and
confirmation data are not shown for PPC. **Staking is not provided.**

See [Peercoin setup and pool references](../mining-coins.md#peercoin-proof-of-work).
The existing coin IDs, saved settings, remote access keys and ASIC safety
protections are preserved. Updating does not switch an existing miner to PPC.

Validation includes official Peercoin address and genesis-block vectors,
coinbase height formats, settings/persistence, candidate records, browser
behavior and the statistics collector. Physical Peercoin pool measurements
remain pending; no PPC hashrate or low-difficulty pool preset is claimed.
