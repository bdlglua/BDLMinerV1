## Complete local website redesign

- Rebuilt the dashboard, settings and activity log with responsive navigation, clear sections, keyboard focus and French/English labels.
- Separate mining statistics, pool/wallet, Bitcoin market data, device health and GitHub updates.
- Show the live 10-second hashrate alongside the 1-minute average, effective/configured mining power and the reason for throttling or a pause.
- Search settings, reveal password fields locally, track unsaved edits and choose Full performance, Balanced or Quiet presets.
- Filter, pause, resume and download the activity log. Restart the miner from authenticated maintenance controls.
- Explain read-only setup errors in the interface and direct USB-only boards to the release download.

## Firmware and performance

- Restore a 100% default mining duty cycle for new configurations. Existing saved limits are preserved; choose **Full performance → Save and restart** to request 100% on an existing miner.
- Keep the accelerated SHA loops and their self-tests, thermal protection, expiring supervision and signed firmware verification.
- Serve deterministic gzip-compressed styles and scripts from flash, with content-versioned browser caching. The UI has no external dependencies.
- Pause polling in hidden tabs and prevent overlapping refreshes after reconnecting or returning to a tab.
- Discard complete invalid/oversized Stratum frames, bound receive work per iteration, limit merkle depth and time out stalled pool handshakes.
- Check service startup failures and report them in diagnostics. Prevent failed mining tasks from leaving phantom engines or a misplaced fill counter.

- Pin the validated PlatformIO toolchain, test USB factory packaging in CI for every board and preserve tool error diagnostics.

## Upgrade notes

Settings and lifetime statistics are preserved. A requested 100% duty cycle retains all hardware and thermal limits: about 1 MH/s depends on a compatible board and suitable cooling. This release does not overclock the chip or guarantee sustained hashrate.

Use the signed GitHub update or the matching `<board>-firmware.bin`. Boards without two application slots require USB.

Validation includes browser regressions, production upload/updater simulations, mining/core and network framing tests, task failure simulations, asset round-trip/cache checks and builds for all 10 supported boards. Physical-device temperature and sustained-hashrate testing remains necessary.
