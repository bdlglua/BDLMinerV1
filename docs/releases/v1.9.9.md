## An audit of all twelve boards

Every variant was reviewed: its build settings, pins, screen, buttons and sensors, and
its release files (chip ids, flash headers, partition tables, embedded firmware,
signatures). Two bugs came out; both are fixed.

- **The ESP32-S3 without a screen boots on 4 MB boards.** Its image said 8 MB of flash in
  its header, and the ESP32-S3 framework stops at boot when the chip is smaller
  ("Detected size smaller than the size in the binary image header"): the many 4 MB S3
  boards, such as the S3 Super Mini, restarted in a loop. The image now says 4 MB, which
  larger chips run as well.
- **The hashrate graph fits small screens.** Its axis labels had a fixed 23 pixels, where
  "1.14M" lost its first digit (".14M"); on 80-pixel-wide screens, the time span and
  "now" overlapped. The axis now takes the width of its widest label (one decimal less
  if it still does not fit), and the time span drops its seconds, then "now", when space
  runs out.

Nothing else changes since [1.9.8](v1.9.8.md).

## Installation and compatibility

Existing BDLMiner devices install their matching signed **`*-firmware.bin`** through
GitHub update discovery (as a firmware trial) or the local firmware-update page;
settings, statistics and the hashrate history are kept. An ESP32-S3 without a screen
stuck in a boot loop with 1.9.8 or earlier needs a USB install: pick *ESP32-S3 without a
screen* in the [web flasher](https://bdlglua.github.io/BDLMinerV1/) or flash its
**`*-factory.bin`** at 0x0. Signed firmware, signatures, factory images, SHA-256
checksums and the web flasher are provided for all **twelve variants**. The default
native user agent is **BDLMinerV1/1.9.9**.

## Validation

- The release files of 1.9.7 and 1.9.8 checked for all twelve boards: chip ids,
  bootloader position, flash size and mode, partition tables with two update slots, the
  firmware inside the factory image, and every signature against the public key. The
  headless ESP32-S3 header now says 4 MB.
- Every screen of every size (80×160, 128×128, 135×240, 160×80, 240×135, 320×170,
  320×240), in English and French, checked on the previews.
- All native host tests, 75 browser regressions and the twelve builds pass.
