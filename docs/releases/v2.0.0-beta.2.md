# BDLMiner 2.0.0-beta.2 — development preview

This version packages the changes made after the owner's beta.1 tests. It is a
development preview, not a published stable release. Stable firmware remains
1.9.15; the CI Linux kit contains unsigned images for manual testing.

- The local dashboard uses the official BDLMiner logo. Dashboard/settings/log
  browser titles and the installed web-app name consistently show V2.
- Records, device health and updates use the page width below the chart/pool
  overview, reducing the empty area caused by a long narrow sidebar. Update
  controls are compact on desktop and stack on mobile.
- The Linux collector distinguishes regulator shutdown bits from warnings such
  as CML, retains failed readings and partial counter progress, and classifies
  transport failures. Statistics GETs receive at most two retries; completed
  windows with read gaps require review and never receive a clean pass.
- The offline kit includes these notes, the latest host tools and the statistics
  service compatibility reference. The owner already deployed that separate
  server fix, allowing beta version labels without changing hardware rate caps.

Mining kernels, clocks, voltage and thermal/fan interlocks are unchanged from the
tested beta.1 build. Beta.1 owner evidence includes a passed one-hour M5 check
and short Gamma checks; the longer Gamma run ended on an HTTP read error after
about 21 minutes while subsequent logs showed continued mining. The origin of
that local HTTP interruption remains unknown. Beta.2 hardware rates, OTA trial/
confirmation/rollback and physical-screen acceptance remain to be observed.

Use the [beta.2 kit instructions](../v2/README.md#beta1-to-beta2-on-the-owners-cards)
for the M5/Gamma manual OTA observers. No script installs firmware automatically.
