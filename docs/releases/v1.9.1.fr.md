## Vérifier les mises à jour sans mot de passe

Sur le tableau de bord, **Vérifier maintenant** (dans la tuile des mises à jour GitHub)
ne demande plus le mot de passe web : ce bouton regarde seulement s'il existe une
version signée plus récente sur GitHub, sans rien installer ni modifier. **Installer**
demande toujours le mot de passe quand il y en a un. Les vérifications demandées sont
limitées à une toutes les 30 secondes, pour que personne sur le réseau ne puisse occuper
le miner avec des connexions TLS.

Rien d'autre ne change depuis la [1.9.0](v1.9.0.md), dont le partage anonyme du hashrate
alimente maintenant les [statistiques BDLMiner](https://bdlminer-stats.bdlminer-bot.workers.dev/) :
le premier rapport est venu d'une carte ESP32 dans l'heure qui a suivi la release.

## Installation et compatibilité

Les appareils BDLMiner déjà installés reçoivent leur **`*-firmware.bin`** signé
correspondant par la recherche de mises à jour GitHub (en période d'essai) ou par la page
locale de mise à jour ; les réglages, les statistiques et l'historique du hashrate sont
conservés. Pour une première installation, choisis la carte dans
l'[installateur web](https://bdlglua.github.io/BDLMinerV1/) ou flashe son
**`*-factory.bin`** à l'adresse 0x0. Firmwares signés, signatures, images complètes,
sommes SHA-256 et installateur web sont fournis pour les **douze variantes**. L'agent
utilisateur natif par défaut est **BDLMinerV1/1.9.1**.
