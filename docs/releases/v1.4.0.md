## Illustrated, smoother physical display

- Redesign the eight device pages: mining, clock, Bitcoin market, network, device information, hashrate history, records and recent blocks. Adapt the layout to landscape, square and small M5 displays.
- Add original Bitcoin-and-pickaxes, clock, network and ASIC illustrations, an illustrated startup screen, and NerdMinerV2-inspired yellow/cyan readouts with BDLMiner branding.
- Replace scaled pixel and seven-segment fonts with native-size, antialiased Sans glyphs. Filter artwork at the panel's actual size and smooth panel corners, indicators and graph lines. Physical LCD resolution still determines the available detail.
- Keep hashrate, temperature, effective power, accepted shares and best difficulty visible on the mining page. Display pauses and thermal limits, retain 32-bit and 64-bit records, and show the local IP on the network page.

## Refresh and memory use

- Redraw only changed fields and redraw the graph when a new sample arrives. Preserve elapsed time, zero values, missing samples and a zero hashrate baseline.
- Reuse one 8 KiB strip buffer instead of allocating sprites per field or a full-screen framebuffer. Clipped direct drawing remains available when the buffer cannot be allocated.
- Store compressed antialiased glyphs and four filtered artwork sources in flash. No runtime font loading, image decoder, filesystem, animation loop or external image request is needed. Headless firmware excludes the display assets.
- Preserve French/English, accent themes, brightness, rotation, screen cycling and night mode. Restore the display after an interrupted firmware update.

Mining kernels, requested power, thermal protection, saved settings and the local web dashboard retain their existing behavior. This release makes no new measured hashrate or temperature claims.

Validation covers the production renderer on seven panel shapes in both languages, fractional glyph coverage, identical buffered/direct output, unchanged-frame caching, long text, missing samples, timer wrap and update recovery. Browser and mining-core regressions are retained, alongside builds and USB packaging for all ten board variants.

## Updating

Use the firmware for the same board as your current installation. Supported OTA updates preserve settings and statistics. Boards without OTA support use USB; a first installation with the web flasher erases the board. The signed firmware and GitHub update manifest are included for all ten variants.
