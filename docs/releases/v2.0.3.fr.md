# BDLMiner 2.0.3

**Partager ma pool anonymement** est désormais activé par défaut sur les nouveaux
appareils et dans les configurations qui ne contiennent pas encore cette option.
La 2.0.2 l’avait introduite désactivée par défaut. Un choix désactivé déjà enregistré
est conservé. L’option reste désactivable dans **Réglages → Réseau → Statistiques
anonymes** et nécessite le partage du hashrate.

Les tableaux de statistiques affichent un lien vers le site officiel de chaque
pool reconnue, avec son URL sous le nom. Les liens sont prédéfinis et ne proviennent
jamais des rapports des mineurs. Aucun lien n’est proposé pour les groupes
**Autre / pool privée** et **Pool non renseignée**.

Seul un groupe de pool publique prédéfini est envoyé ; les hôtes privés ou
personnalisés deviennent **Autre / pool privée** sur la carte. Aucun hôte configuré,
port, adresse Bitcoin ni worker n’est envoyé. Les douze profils signés et les
protections de minage, thermiques, électriques et de mise à jour sont conservés.
