## Live dashboard, settings without restart, more memory

**Stratum V2 disconnections fixed.** A V2 pool may announce the job for the next block
long before that block arrives, then send several template updates. The miner kept 8
jobs and replaced the oldest, the announced one included, so the new block pointed to a
job it no longer had: "SV2: Unknown SV2 future job" and a reconnection. Announced jobs
and the current one are now kept until their block arrives.

**Pool statistics outages shown.** When the pool's statistics API stops answering
(as public-pool's did), the *Seen by the pool* and *Integrations* tiles say so, the
share-based estimate stands in, and the miner asks again after 10 minutes instead of
an hour.

**Live dashboard.** The miner pushes its statistics every 2 seconds to up to two open
dashboards (Server-Sent Events); other pages, or a lost stream, fall back to polling.

**Settings without a restart.** Numbers and switches (brightness, rotation, theme,
language, night mode, alerts, temperature limit, mining power, battery saver,
updates...) apply at once; the button reads *Save*. Text, pool, WiFi and MQTT
settings still restart the miner.

**Memory for updates and notifications.** Notifications are now sent by the task
that already fetches market data: about 13 KB more free memory. The memory check for
TLS connections follows what a session needs (54 KB free, a 24 KB block) instead of a
fixed 70 KB that a running miner no longer reached, which held back market data,
notifications and GitHub updates. A notification waits for memory instead of using
up its tries.

**Crash history.** The last 5 crashes are kept with the version that crashed and the
date, even after the report itself is replaced or erased.

**Integrations and pool reliability.** An *Integrations* tile shows MQTT, the last
notification and each destination's answer, and the pool statistics source. The pool
tile shows the time connected since restart, reconnections and switches to backup.

**Faster pool API search.** Probing a port that does not speak TLS now gives up after
6 seconds instead of about 18.

## Installation and compatibility

Existing BDLMiner devices install the matching signed **`*-firmware.bin`** through
GitHub update discovery (a miner on 1.6.8 tries it as a firmware trial) or the local
firmware-update page. For M5StickC Plus2, use **`m5stickc-plus2-firmware.bin`**.
Settings and saved statistics are kept. Signed firmware, signatures, factory images,
SHA-256 checksums and the web flasher are provided for all **eleven variants**. The
default native user agent is **BDLMinerV1/1.6.9**.

## Validation

- 72 browser regressions, native host tests and eleven board builds.
- On an M5StickC Plus2: free memory 80-85 KB instead of 59-66 KB, market data
  refreshing again, the crash history recording the existing report, the live stream
  (2 dashboards, a third refused, the normal API still answering in 75 ms) and a
  browser dashboard following it without polling.
