# BDLMiner 2.0.0-beta.1 — development notes

Development branch only. This file does not mean that a release has been published.

- Optional Linux/Raspberry Pi fleet hub with live M5/Gamma/NerdNOS cards, bounded
  polling, SQLite history, offline states and English/French controls.
- One-click diagnostics for the current Stratum V1/V2 session, ASIC version
  rolling, missing work and statistically infrequent shares.
- Supervised Gamma frequency calibration with measured counter rates, continuous
  telemetry checks, cancellation, restored settings and crash-recovery checkpoints.
- Separate local/pool/share-based rates, sample counts and rejected-share causes.
- Configurable metric order and enabled pages on physical screens; native Gamma 128×32
  rendering and existing block/fault/update message priority are preserved.
- Opt-in stable/beta channels with SemVer ordering, existing signed firmware
  verification and OTA trial/rollback. Stable remains the default channel.
- Linux hardware bench with explicit pass/fail/skip results and optional signed
  OTA, physical-reset and router fault hooks. Release workers build all twelve
  boards in parallel; a separate aggregate job verifies and signs the images.

Mining kernels, clocks, voltage settings, fan/electrical/thermal interlocks and
lifetime-statistics persistence are unchanged. The pool identity remains
`BDLMinerV1/<firmware version>` for existing pool classification compatibility.
V2 software tests do not replace real board, cooling, display and OTA validation.
See [the V2 guide](../v2/README.md) for setup, limits and test commands.
