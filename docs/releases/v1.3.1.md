## Maintenance release

- Align the default firmware version with the v1.3.1 release tag and the README release instructions. Local builds, signed release binaries and the web flasher report 1.3.1.
- Rebuild the ten supported board variants with signed firmware, USB factory images and the GitHub update manifest.

This release retains the v1.3.0 dashboard, interactive 1 h / 6 h / 24 h charts, CSV exports and on-demand diagnostics. It introduces no changes to mining kernels, requested power, thermal protection or settings storage, and makes no new hardware performance claims.

The [English Reddit screenshot bundle](https://github.com/bdlglua/BDLMinerV1/raw/8bf7ae734528374b95e326284bf8a575a482c097/BDLMiner-Reddit-English.zip) remains available as a direct download. These interface screenshots were captured from v1.3.0 using clearly labelled demonstration data; they are not measurements from a physical miner.

For an existing miner, install the firmware for the same board through its supported update method. Reload the local dashboard after updating. A first installation with the USB web flasher erases settings and statistics.
