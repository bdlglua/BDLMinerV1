# BDLMiner 2.1.1

**Settings → Pool → User agent** is now a single dropdown with exactly two
choices: **NerdMinerV2** and **BDLMinerV2/2.1.1**. The setup portal and interactive
demo use the same choices. The Automatic/Manual selector and free-text field are
removed; the dashboard shows the identity actually sent without a mode label.

Both Stratum V1/V2 and main/backup pools use the selected identity. A refusal does
not silently replace it. Native BDLMiner identities follow the firmware version;
a saved NerdMinerV2 choice survives restarts, updates and backup restoration.
Old custom identities migrate to the current native choice. The obsolete mode
flag remains false in saved records for OTA rollback compatibility.

BTC/BCH selection, mining kernels, ASIC safeguards, signed updates and rollback
protection are unchanged.
