## Check now without the password

On the dashboard, **Check now** (in the GitHub update tile) no longer asks for the web
password: it only looks for a newer signed release on GitHub, without installing or
changing anything. **Install** still asks for the password when one is set. Requested
checks are limited to one every 30 seconds, so that nobody on the network can keep the
miner busy with TLS handshakes.

Nothing else changes since [1.9.0](v1.9.0.md), whose anonymous hashrate sharing now
feeds the [BDLMiner statistics](https://bdlminer-stats.bdlminer-bot.workers.dev/): its
first report came from an ESP32 board within the hour after the release.

## Installation and compatibility

Existing BDLMiner devices install their matching signed **`*-firmware.bin`** through
GitHub update discovery (as a firmware trial) or the local firmware-update page;
settings, statistics and the hashrate history are kept. For a first install, pick the
board in the [web flasher](https://bdlglua.github.io/BDLMinerV1/) or flash its
**`*-factory.bin`** at 0x0. Signed firmware, signatures, factory images, SHA-256
checksums and the web flasher are provided for all **twelve variants**. The default
native user agent is **BDLMinerV1/1.9.1**.
