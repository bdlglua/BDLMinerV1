# BDLMiner V2 2.3.1

Fixes and security hardening; settings, statistics and mining kernels are unchanged.

## Fixes

- **DigiByte SHA-256d mining works.** DigiByte marks SHA-256d jobs with version
  bits `0x200` (zero is Scrypt); every real DGB SHA-256d job was refused with
  *DGB requires a SHA-256d pool*. Scrypt jobs and masks that roll the algorithm bits
  are still refused.
- **Bitaxe Gamma 601: no more frequent *Initializing BM1370*.** A pool reconnection
  or failover no longer powers the ASIC off and repeats its 9-second start: it keeps
  running on its last job for up to 60 seconds (*Waiting for pool*), its results
  discarded. Safety pauses still stop it at once.
- **NerdNOS:** results in flight after a pool difficulty change are no longer counted
  as hardware errors.
- **Rejected shares** answered without a reason no longer reuse the reason of an
  earlier rejection.
- **Daily summary:** a summary skipped right after a start no longer leaves its best
  difficulty to the next day's summary.
- **Log:** a message longer than 255 characters no longer joins the next line;
  an unreadable release version no longer reads as a beta-channel error.

## Security

- **HTTPS certificates are verified.** ntfy, webhooks, market data, pool statistics
  and hashrate sharing now check the server's certificate and name against about
  40 public root authorities. A failure is never retried without verification, so a
  webhook URL (a Discord or Telegram token) or ntfy topic cannot be read on the way.
  **A self-signed ntfy server or webhook is now refused** (*certificate not trusted*
  in the notification test): use an `http://` URL for such a server on the local
  network. Nothing is sent before NTP has set the clock. GitHub downloads use the
  same verification but keep working if a certificate cannot be verified, the
  firmware being trusted by its signature.
- **The log page asks for the web password** when one is set, like the settings.

## Validation

Host regressions cover every fix (production Gamma worker loop through pool
outages and busy job boards, NerdNOS filters, log access, TLS trust and fallback,
certificate bundle lookup), with all browser tests and builds of every board. The
certificate bundle adds 17 KB; the fullest 4 MB board keeps 49 KB free. No physical
board was used for this validation.
