# BDLMiner 2.2.0

**Bitcoin SV (BSV)**, **eCash (XEC)** and **DigiByte SHA-256d (DGB)** join BTC and
BCH in **Settings → Pool → Cryptocurrency**. The portal, dashboard, physical
screens, fleet hub, demo and anonymous statistics identify all five profiles.
Existing BTC/BCH choices are preserved. The native user agent follows version
2.2.0; a selected NerdMinerV2 identity remains selected.

The new profiles use Stratum V1 and matching pool/address or account settings.
XEC CashAddr and DigiByte Base58/Bech32/Bech32m checks use their own prefixes.
BSV uses legacy Base58Check. DGB jobs from other algorithms and version masks
that roll algorithm bits are refused by the network and mining engine.

Bitcoin market/explorer data is not used for other profiles, and the DGB display
does not use Bitcoin's halving interval. Saved proofs retain their original coin.
New-profile NVS records are rejected by older firmware rather than silently
becoming BTC settings after rollback. See [setup and backup details](../mining-coins.md).

The hashing kernels, signatures, thermal/electrical safeguards and pool
requirements are unchanged. Software checks cover official address vectors,
pool/algorithm guards, persistence and UI behavior. Physical BSV/XEC/DGB pool
measurements remain pending. A profile cannot change the chain served by a pool.
