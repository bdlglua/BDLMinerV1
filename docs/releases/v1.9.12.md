## Correct share accounting and a quieter dashboard in the background

Version 1.9.12 includes the fixes from the [1 November repository review](../audits/2026-11-01.md).

### Mining and pool statistics

- Accepted work retains the difficulty assigned to each submitted share, even
  when a pool changes its difficulty before replying. This fixes the dashboard's
  share-based hashrate estimate in Stratum V1 and V2, including batched V2 replies.
- Recent shares are matched to their reply IDs. Out-of-order replies mark the
  correct share; an answer for an older, evicted row cannot settle a newer one.
- A regression test exercises real accounting over 7,200 irregular intervals,
  including 32-bit counter wraps, 1.0/1.2 MH/s readings and decay to zero after stopping.

### Local dashboard and integrations

- Hidden tabs close their live statistics stream. Returning to the page opens
  one stream again; the ten-second polling fallback remains available.
- An older snapshot of the same boot cannot rewind the live readings or reset
  the history session.
- MQTT power and brightness commands require a complete integer from 0 to 100.
  Partial values, fractions, embedded NULs and oversized numbers are rejected.
- ASIC settings explain their actual two-minute thermal pause and cooldown,
  in English and French. ESP32 boards keep their own thermal-step explanation.

### Public site and release tools

- The chat display retains the newest 100 messages, matching its internal limit,
  and stops voice playback belonging to an evicted message.
- Audio contexts close even when a voice message cannot be decoded.
- Browser jobs use Ubuntu 24.04, supported by the pinned Playwright version.
  Ubuntu 26.04 on `ubuntu-latest` had stopped CI and releases before tests ran.

### Installation and compatibility

Existing devices can install their matching signed **`*-firmware.bin`** through
GitHub update discovery or the local firmware-update page. Settings, lifetime
statistics and hashrate history are kept. For a first installation, use the
[web flasher](https://bdlglua.github.io/BDLMinerV2/) or flash the matching
**`*-factory.bin`** at address **0x0**.

Signed firmware, signatures, factory images, SHA-256 checksums and the web flasher
are provided for all **twelve variants**. The default native user agent is
**BDLMinerV1/1.9.12**. Gamma 601 and NerdNOS support remains experimental.

### Validation

- Full native suite, independent Stratum V2 responder/crypto checks and ASIC fault tests.
- **82 browser regressions**, **16 tool tests** and builds for all **12 variants**.
- Display-renderer checks at seven dimensions in English and French.

Mining kernels, clocks and thermal protection retain their existing settings.
The reported M5StickC Plus2 1.20-to-1.00 MH/s fluctuation still requires a log
capturing the event; no physical hashrate improvement is claimed for this release.
