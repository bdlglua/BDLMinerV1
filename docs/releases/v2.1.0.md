# BDLMiner 2.1.0

Choose **Bitcoin (BTC)** or **Bitcoin Cash (BCH)** in **Settings → Pool →
Cryptocurrency**. Existing settings remain on BTC. BCH uses Stratum V1, standard
CashAddr or legacy addresses, and a matching pool endpoint/account; main and
backup pools must serve the selected coin. Changing a profile restarts the miner.

The local dashboard, API, hub and physical crypto screen identify the selected
coin. Known BTC-only endpoints and BCH/V2 configurations are refused. Pool jobs
still determine the actual chain; a selector cannot convert a BTC-only pool.
Bitcoin market/API discovery and mempool.space block confirmation are disabled
for BCH. Saved block proofs retain their original coin.

Anonymous reports include the fixed coin ticker and the public statistics show
separate BTC/BCH totals. Existing sharing choices and private endpoint masking
are preserved. No address, worker or miner identifier is added.

SHA-256d kernels, thermal/electrical safeguards, signature checks and OTA rollback
are unchanged. CashAddr vectors, configuration/persistence, block-proof isolation,
Stratum sessions and browser regressions cover the feature in software. Physical
BCH pool measurements are still pending. See [BTC / BCH setup](../mining-coins.md)
for pool difficulty, ASIC version-rolling and address/account requirements.
