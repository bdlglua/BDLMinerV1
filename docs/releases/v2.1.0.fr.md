# BDLMiner 2.1.0

Choisis **Bitcoin (BTC)** ou **Bitcoin Cash (BCH)** dans **Réglages → Pool →
Cryptomonnaie**. Les configurations existantes restent sur BTC. BCH utilise
Stratum V1, des adresses CashAddr standard ou historiques et une pool/adresse
ou un compte adaptés. Les pools principale et de secours doivent servir la même
monnaie. Le changement redémarre le mineur.

Le dashboard local, l’API, le hub et l’écran crypto identifient la monnaie choisie.
Les services connus réservés à BTC et les configurations BCH/V2 sont refusés.
La pool fournit toujours la chaîne réellement minée : le menu ne transforme pas
une pool Bitcoin en pool BCH. Les données du marché/API Bitcoin et la confirmation
des blocs par mempool.space sont désactivées pour BCH. Les preuves de blocs
sauvegardées conservent leur monnaie d’origine.

Les rapports anonymes incluent le symbole prédéfini de la monnaie et les
statistiques publiques distinguent BTC/BCH. Les choix de partage et le masquage
des pools privées sont conservés. Aucune adresse, aucun worker ni identifiant de
mineur n’est ajouté.

Les moteurs SHA-256d, les protections thermiques/électriques, les signatures et le
retour arrière OTA sont conservés. Les tests logiciels couvrent CashAddr, les
réglages et leur persistance, l’isolation des preuves, Stratum et le navigateur.
Les mesures physiques sur une pool BCH restent à faire. Le [guide BTC / BCH](../mining-coins.md)
précise la difficulté, le version rolling des ASIC et les comptes/adresses requis.
