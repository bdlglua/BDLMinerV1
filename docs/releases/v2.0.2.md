# BDLMiner 2.0.2

The public statistics now group miners by pool, with a miner count and combined
hashrate for each group. The table is available on the BDLMiner website and on the
statistics service.

Enable **Settings → Network → Anonymous statistics → Share my pool anonymously**
to contribute. It is off by default, including after an update, and also requires
**Share my hashrate anonymously**. Both options apply without restarting.

Only a fixed public pool group is sent. Other hosts become **Other / private pool**
on the device; the configured hostname, port, Bitcoin address and worker are never
sent. The connected backup pool is used when active. Older firmware, pool sharing
disabled and disconnected pools remain counted under **Not shared**.

All twelve board profiles retain signed updates and automatic rollback. The
existing physical measurements remain those recorded for the M5StickC Plus2 and
Gamma 601; this release makes no new hardware performance claims.
