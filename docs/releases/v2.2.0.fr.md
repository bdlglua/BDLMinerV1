# BDLMiner 2.2.0

**Bitcoin SV (BSV)**, **eCash (XEC)** et **DigiByte SHA-256d (DGB)** rejoignent BTC
et BCH dans **Réglages → Pool → Cryptomonnaie**. Le portail, le dashboard, les
écrans, le hub, la démo et les statistiques anonymes identifient les cinq profils.
Les choix BTC/BCH existants sont conservés. Le user agent natif suit la version
2.2.0 ; un choix NerdMinerV2 est conservé.

Les nouveaux profils utilisent Stratum V1 et une pool/adresse ou un compte
adaptés. CashAddr XEC et Base58/Bech32/Bech32m DigiByte utilisent leurs propres
préfixes. BSV utilise Base58Check historique. Pour DGB, le réseau et le moteur
refusent les jobs des autres algorithmes et les masques qui changeraient ces bits.

Les données du marché et de l’explorateur Bitcoin ne sont pas utilisées pour les
autres profils ; DGB n’affiche pas l’intervalle de halving Bitcoin. Les preuves de
blocs conservent leur monnaie. Les configurations NVS des nouveaux profils sont
refusées par les anciens firmwares plutôt que réinterprétées comme BTC après
retour arrière. Voir les [réglages et sauvegardes](../mining-coins.md).

Les moteurs de calcul, signatures, protections thermiques/électriques et exigences
des pools sont conservés. Les tests logiciels couvrent les adresses officielles,
les contrôles de pool/algorithme, la persistance et l’interface. Les mesures réelles
sur une pool BSV/XEC/DGB restent à faire. Un profil ne change pas la chaîne servie
par une pool.
