## Pool statistics from more pools

**More pools recognised.** The automatic search for a pool's statistics now also tries
`/api/miner?address=<address>`, the ckpool-format API of pools such as
pool.nerdminer.io, on the pool's host and its parent domain.

**Searched again after the first share.** Most pools publish an address only once it
has an accepted share, so a new miner found nothing and waited 6 hours. A fruitless
search now runs again after the next accepted share (at most every 30 minutes).

**Quieter log.** A search attempt that gets no answer is an expected result: it is no
longer logged as a red TLS failure; the search reports its outcome in one line.

Everything else is unchanged from [1.7.0](v1.7.0.md): hashrate history kept across
restarts, daily summary, recent shares, no false alarm after a power cut during an
update trial.

## Installation and compatibility

Existing BDLMiner devices install the matching signed **`*-firmware.bin`** through
GitHub update discovery (as a firmware trial) or the local firmware-update page. For
M5StickC Plus2, use **`m5stickc-plus2-firmware.bin`**. Settings, statistics and the
hashrate history are kept. Signed firmware, signatures, factory images, SHA-256
checksums and the web flasher are provided for all **eleven variants**. The default
native user agent is **BDLMinerV1/1.7.1**.

## Validation

- 74 browser regressions, native host tests and eleven board builds.
- On an M5StickC Plus2 mining on pool.nerdminer.io: the new API format is tried on the
  pool and its parent domain, and the log no longer shows failed probes. Finding the
  API after the first accepted share could not be observed yet (difficulty 1, about
  one share an hour).
