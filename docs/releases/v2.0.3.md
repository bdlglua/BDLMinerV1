# BDLMiner 2.0.3

**Share my pool anonymously** is now on by default for new devices and settings
records that predate the option. The 2.0.2 release introduced it with a disabled
default. An existing saved disabled choice is preserved. The option remains
independently switchable in **Settings → Network → Anonymous statistics** and
requires hashrate sharing.

The statistics tables link each recognised pool to its official website and show
the URL below the name. Links come from a fixed public catalog, never from miner
reports. Private/other and undisclosed groups have no link.

Only a fixed public pool group is sent; private/custom endpoints become **Other /
private pool** on the device. The configured host, port, Bitcoin address and worker
are never sent. All twelve signed board profiles are retained, with no changes to
mining, thermal, electrical or update-signature safeguards.
