# BDLMiner V2 2.3.4

Thermal safety fixes; settings, statistics and mining kernels are otherwise unchanged.

- **Bitaxe Gamma 601: the user thermal limit now pauses before the hard stop.**
  *Pause mining above* accepted up to 255 °C, but the ASIC's hard stop at 70 °C
  latches until a restart. A limit of 70 °C or more therefore never paused and cooled
  the board first: mining simply stopped until someone restarted it. The limit is now
  at most **68 °C** (0 = off is still allowed); a higher saved value is lowered to 68 °C.
- **NerdNOS: hard stop at 80 °C.** The board has no fan control, and its only thermal
  protection was the user limit, which can be off (0) or set higher than the stock
  firmware's 80 °C cut. The driver now stops the ASIC at 80 °C on its NTC whatever
  the settings, and restarts it at 70 °C; a lost reading never ends the cooling.

## Validation

Host regressions cover the Gamma limit (68 °C accepted, 69-75 °C refused, 0 kept)
and the NerdNOS hard stop and hysteresis, with all host, browser and board builds.
No physical board was used for this validation.
