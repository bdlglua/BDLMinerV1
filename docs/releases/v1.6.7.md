## Clearer GitHub update checks

**Check now** no longer reports "GitHub updates are disabled or busy" when a check
is already running: that check answers the request, so it is accepted and the
dashboard shows *Check requested*. The two real refusals now say what they are:
updates disabled in the settings, or an installation in progress (both translated
into French).

Everything else is unchanged from [1.6.6](v1.6.6.md): the one-big-number screen, the
console dashboard, the pool-side hashrate estimate and the smaller firmware with two
firmware slots on every 4 MB board.

## Installation and compatibility

Existing BDLMiner devices install the matching signed **`*-firmware.bin`** through
GitHub update discovery or the local firmware-update page. For M5StickC Plus2, use
**`m5stickc-plus2-firmware.bin`**. Settings and saved statistics are kept by an
application update. M5Stack Core and CYD boards installed before 1.6.6 need one USB
or [web flasher](https://bdlglua.github.io/BDLMinerV1/) reinstall with a factory image
to get their second firmware slot.

Signed firmware, signatures, factory images, SHA-256 checksums and the web flasher are
provided for all **eleven variants**. The default native user agent is
**BDLMinerV1/1.6.7**.
