# BDLMiner 2.0.1

Finalisation du nom V2 sur le firmware, le site et les liens du projet.

- Nom **BDLMiner V2** dans le portail, le journal de démarrage, l'écran d'accueil
  et les guides actuels. Le réseau Wi-Fi de configuration devient
  `BDLMinerV2-XXXX`.
- Identité native du pool : `BDLMinerV2/<version>`. Les anciennes identités
  natives V1/V2 suivent la version actuelle ; les identités personnalisées et
  le repli de compatibilité NerdMiner existant sont conservés.
- Mises à jour, rapports d'utilisation, outils et documentation vers
  `bdlglua/BDLMinerV2`, avec l'installateur sur
  <https://bdlglua.github.io/BDLMinerV2/>.
- Signatures, Wi-Fi et pool enregistrés, statistiques cumulées, boucles de
  minage, fréquences et protections conservés. Des marqueurs techniques anciens
  restent présents pour les outils de vérification OTA déjà distribués.

La 2.0.0 reste disponible. Ce correctif ne constitue pas une nouvelle mesure
physique de débit ou de température.

## Appareils déjà installés

Le canal stable utilise les redirections GitHub tant que l'ancien nom reste
libre. Ne pas créer un autre dépôt `BDLMinerV1`, car cela supprimerait ces
redirections.

**GitHub Pages ne redirige pas automatiquement l'ancienne adresse du site.**
Utiliser le nouvel installateur indiqué ci-dessus. Sur une version 2.0.0 ou
antérieure utilisant le canal bêta, choisir **stable** dans les réglages de mise
à jour puis lancer une vérification, ou envoyer le `<carte>-firmware.bin`
correspondant depuis le dashboard existant. Ne pas envoyer d'image factory en
OTA. Après installation de la 2.0.1, le canal bêta utilise la nouvelle adresse.

Le [bilan de migration](../v2/repository-migration.md) décrit les étapes et
distingue les tests automatisés des vérifications réelles après renommage.
