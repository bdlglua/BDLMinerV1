## The exact model of M5Stack boards

The [BDLMiner statistics](https://bdlminer-stats.bdlminer-bot.workers.dev/) and the
[site](https://bdlglua.github.io/BDLMinerV1/#stats) now tell M5Stack boards apart. The
M5Stack firmware serves several models (Core, Core2, Tough, StickC Plus, Atom…, and on
ESP32-S3 the AtomS3, CoreS3, Cardputer…), which it already detects at boot for its
screen: the anonymous hashrate report now names that model, for instance
`{"v":"1.9.4","board":"m5stack-esp32","hashrate":1.02e6,"every":300,"model":"M5Stack Core2"}`.
On the site, *Devices* lists the models online under their firmware and *By board*
shows one line per model.

The model is sent only when it says more than the firmware's own name; the other
boards send exactly what they did. Nothing else changes in the report: no address,
worker, pool, name or identifier. *Settings* → *Anonymous statistics* → **Share my
hashrate anonymously** still turns it off.

The statistics service also counts at once several miners of one board that start
together; they were counted as one until their reports covered five minutes.

Nothing else changes since [1.9.3](v1.9.3.md).

## Installation and compatibility

Existing BDLMiner devices install their matching signed **`*-firmware.bin`** through
GitHub update discovery (as a firmware trial) or the local firmware-update page;
settings, statistics and the hashrate history are kept. For a first install, pick the
board in the [web flasher](https://bdlglua.github.io/BDLMinerV1/) or flash its
**`*-factory.bin`** at 0x0. Signed firmware, signatures, factory images, SHA-256
checksums and the web flasher are provided for all **twelve variants**. The default
native user agent is **BDLMinerV1/1.9.4**.
