## No more sign-in on the local dashboard

The settings, the log, backups and firmware updates of the local dashboard now open
directly, without asking for a user name and password.

- The **web password is optional** and empty by default. Without one, nothing is ever
  asked. Updating to 1.9.3 **removes, once, a password set with an earlier version**,
  so that no sign-in window appears after the update either.
- To protect a miner on a network you share, set a password again in *Settings* →
  *Network* → **Web password** (or in the setup portal): it is then asked before any
  change, as before, and kept across updates. Clearing the field removes it.
- Without a password, **anyone on your local network can change the settings**,
  including the payout address, download backups (they hold the WiFi password) and
  upload a firmware. Keep the miner on your home network and never forward its port
  80 to the internet; see the [security policy](../../SECURITY.md).

Nothing else changes since [1.9.2](v1.9.2.md).

## Installation and compatibility

Existing BDLMiner devices install their matching signed **`*-firmware.bin`** through
GitHub update discovery (as a firmware trial) or the local firmware-update page;
settings, statistics and the hashrate history are kept (the web password excepted, as
above). For a first install, pick the board in the
[web flasher](https://bdlglua.github.io/BDLMinerV1/) or flash its **`*-factory.bin`** at
0x0. Signed firmware, signatures, factory images, SHA-256 checksums and the web flasher
are provided for all **twelve variants**. The default native user agent is
**BDLMinerV1/1.9.3**.
